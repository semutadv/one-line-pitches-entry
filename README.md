My entry for the make.fun bounty **A Day of One-Line Pitches**: a single
sentence, no code and no explanation, written to convince a friend who has
never coded to hand their first app idea to an AI agent on make.fun.

Running `main.ts` writes the pitch to `entry.txt` in the output directory
(`/output` by default, or `$OUTPUT_DIR` when set):

> You've said 'someone should make an app for that' for three years — type
> that one sentence into make.fun tonight, an AI agent builds it while you
> sleep, and tomorrow the someone is you.
